# 异变缝合兽 建模流水线

正典：`docs/worldview.md` §七 L735 · 图书馆《异兽三形考》§兽·噬 / 《异变图谱·残卷》其三。

> 非凭空生，乃数兽相吞融成。……不是物理接合——是一层层组织的重新编织，骨对着骨重新接，
> 皮对着皮重新缝。这不是魔功。这是一种余不知名的**塑性再生**。

三形（噬元鼠 ✅ / 拟态灰烬蛛 ✅ / 缝合兽）之末。此前客户端只有 4 骨 5 方块的占位。

## 设计主轴

缝合兽和其它生物的根本区别：**它没有固定形态**。每一只都是不同几只野兽的残骸长到一起的
结果。所以这条流水线产出的不是"一个模型"，而是**一个生成器**——核心固定，肢体/头颅由
基因组随机装配。

三层：

| 层 | 内容 | 状态 |
|----|------|------|
| 核心层 | 黏状核心本体 + 挂载点 + 癒合痕 | ✅ |
| 部件层 | 头颅库（鼠/狼/猪/牛/羊/鸡/羊/狐）+ 肢体库（蛛足/兽腿/禽腿/触手/退化肢） | ⬜ |
| 运动层 | 按肢体几何派生的步态 + 逐肢攻击方式 | ⬜ |

## 核心层：一切都从同一个隐式场里派生

核心不建成箱子——箱子是"设计过的形状"，而这东西没有被设计过。改用各向异性高斯和：

```
f(p) = Σ wᵢ · exp(-|(p - cᵢ)/sᵢ|²)      等值面 f = 1 即表皮
```

四件东西全部从这一个场里掉出来，没有一件是手摆的：

| 派生物 | 怎么来的 |
|--------|---------|
| 几何 | 等值面体素化 → 逐层贪心矩形合并 → **只留表层**（内部块永远看不见） |
| 骨骼 | 每体素归属于对它贡献最大的**正权** lobe，lobe 即骨 |
| 癒合痕 | 两个 lobe 在表面的交界处即是痕——与骨骼分段共用同一划分 |
| 挂载点 | 从核心内部射线求表面点，法向取 `-∇f`，girth 由局部平坦度定 |

**负权 lobe（`GROOVES`）用来刻沟**：高斯和永远是凸的，只加正权必然鼓成一只圆面包。
交界处刻沟，才读得出"几团东西挤在一张皮里"。负权段不参与 `owner()`，不抢骨骼归属。

## 两条不许改回去的决策

**① 不对称是硬约束，不是缺陷。** `lump_l` 长在左肋、`lump_dorsal` 偏右背、`nodule_r`
在右后。自检**断言不对称度 ≥20%**（当前 32.4%），报错文案直接写明"别去平衡 LOBES"。
`voxel_rig.mirror_problems` 在这里是反着用的——镜像件缺失是期望行为。

**② 融合痕不是缝合口。** 没有线、没有针、没有等距横扣——那是人造缝合的读法。正典写的是
自体"塑性再生"，留下的是不规则隆起：粗细逐段随机、一成几率断开（融合彻底处无痕）、
一成几率堆成肉瘤。自检卡「粗细跨度 ≥0.35」+「至少一处肉瘤」防它被做回等粗等距。

## 命令

```bash
python3 scripts/models/stitched_beast/gen_core.py            # 生成 + 全部自检
python3 scripts/models/stitched_beast/gen_core.py --check    # 只自检不写文件
python3 scripts/models/stitched_beast/preview.py --three-view
python3 scripts/models/stitched_beast/preview.py --sockets   # 挂载点针（红=肢 蓝=头 黄=退化）
```

`.bbmodel` 落 `scripts/models/local_models/`（gitignored）；渲染图落 `renders/`。

## 文件

| 文件 | 职责 |
|------|------|
| `core.py` | 场定义 / 体素化 / 合并 / 癒合痕 / 挂载点枚举——纯几何，不碰 bbmodel |
| `gen_core.py` | 场 → `.bbmodel` + 八项自检 |
| `preview.py` | 渲染；`--sockets` 把挂载点渲成从表皮戳出的针，肉眼验位置 |

## 当前数字

278–289 块 / 8 骨 / 17 挂载点（肢 ×8 · 头 ×5 · 退化 ×4），本体 1.79 × 1.48 × 2.02 格，
腹底 y≈12.9 给腿层留空间，不对称度 32.4%。

## 已知局限

- 顶视轮廓仍偏矩形——体素网格轴对齐的固有代价，靠抖动和跨度上限只能缓解不能消除。
- 「几只野兽融成一只」这个读法目前只靠癒合痕承担；真正落地要等部件层把头和肢挂上去。
- 挂载点的 `girth` 目前区分度窄（3.7–4.1），赘生物上的槽还没被真正卡住——等部件层
  有粗细不同的真实部件时才知道这个量够不够用。
