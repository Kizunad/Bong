# 异变缝合兽 建模流水线

正典：`docs/worldview.md` §七 L735 · 图书馆《异兽三形考》§兽·噬 / 《异变图谱·残卷》其三。

> 非凭空生，乃数兽相吞融成。……不是物理接合——是一层层组织的重新编织，骨对着骨重新接，
> 皮对着皮重新缝。这不是魔功。这是一种余不知名的**塑性再生**。

三形（噬元鼠 ✅ / 拟态灰烬蛛 ✅ / 缝合兽）之末。此前客户端只有 4 骨 5 方块的占位。

## 设计主轴

缝合兽和其它生物的根本区别：**它没有固定形态**。每一只都是不同几只野兽的残骸长到一起的
结果。所以这条流水线产出的不是"一个模型"，而是**一个生成器**——核心固定，肢体/头颅由
基因组随机装配。

三层：

| 层 | 内容 | 状态 |
|----|------|------|
| 核心层 | 黏状核心本体 + 挂载点 + 癒合痕 | ✅ |
| 基因组 | 挑槽 / 挑部件种类 / 供体物种 / 尺寸——一只兽的配方 | ✅ |
| 运动层 | 骑乘高度 + 步态（由肢体几何推导）| ✅ |
| 核心动画 | 无肢阶段九条动作：蠕动 / 搏动 / 扑咬 / 包裹 / 嫁接 / 爆体 / 分裂 / 受击 / 死 | ✅ |
| 碎裂层 | 分裂 / 爆体碎片 / 各碎片逃窜 / 繁殖闭合 | ✅ |
| 部件层·肢体 | 十五副物种骨架 + 四类站姿 + 真实的蹄/爪/人足/禽爪 + 毛羽鬃 | ✅ |
| 部件层·头颅 | 十种供体的头：脑颅/齿/颌关节/咀嚼肌/眼位/耳/角全部由食性推出 | ✅ |
| 攻击层 | 逐肢攻击方式（由该肢的种类与长度派生） | ⬜ |

## 核心层：一切都从同一个隐式场里派生

核心不建成箱子——箱子是"设计过的形状"，而这东西没有被设计过。改用各向异性高斯和：

```
f(p) = Σ wᵢ · exp(-|(p - cᵢ)/sᵢ|²)      等值面 f = 1 即表皮
```

四件东西全部从这一个场里掉出来，没有一件是手摆的：

| 派生物 | 怎么来的 |
|--------|---------|
| 几何 | 等值面体素化 → 逐层贪心矩形合并 → **只留表层**（内部块永远看不见） |
| 骨骼 | 每体素归属于对它贡献最大的**正权** lobe，lobe 即骨 |
| 癒合痕 | 两个 lobe 在表面的交界处即是痕——与骨骼分段共用同一划分 |
| 挂载点 | 从核心内部射线求表面点，法向取 `-∇f`，girth 由局部平坦度定 |

**负权 lobe（`GROOVES`）用来刻沟**：高斯和永远是凸的，只加正权必然鼓成一只圆面包。
交界处刻沟，才读得出"几团东西挤在一张皮里"。负权段不参与 `owner()`，不抢骨骼归属。

## 两条不许改回去的决策

**① 不对称是硬约束，不是缺陷。** `lump_l` 长在左肋、`lump_dorsal` 偏右背、`nodule_r`
在右后。自检**断言不对称度 ≥20%**（当前 32.4%），报错文案直接写明"别去平衡 LOBES"。
`voxel_rig.mirror_problems` 在这里是反着用的——镜像件缺失是期望行为。

**② 融合痕不是缝合口。** 没有线、没有针、没有等距横扣——那是人造缝合的读法。正典写的是
自体"塑性再生"，留下的是不规则隆起：粗细逐段随机、一成几率断开（融合彻底处无痕）、
一成几率堆成肉瘤。自检卡「粗细跨度 ≥0.35」+「至少一处肉瘤」防它被做回等粗等距。

## 运动层：步态是算出来的，不是调出来的

**肢体是复摆。** 绕髋自然摆频 `f = (1/2π)√(MgD/I)`，均匀杆退化为 `f ∝ 1/√L`：长肢慢、
短肢快。这是物理，不是风格。

**一只兽只有一个速度 ⇒ 错拍是推论。** 一个身体周期内第 i 条肢必须走整数步
`n_i = max(round(f_i/f_body), ⌈v/(f_body·s_i^max)⌉)`——第二项是"跟不上就碎步"。
于是短腿一周期迈两三步、长腿迈一步。**缝合兽走不出齐步是算出来的**，不是为了怪而
故意错开。实测 10/10 个体走非 1:1 步态，最多出到 **1:2:3:4**。

**骑乘高度是自变量。** 撑高则短肢够不着地被踢出承重集，蹲低则长肢折起、可达半径缩水。
高度写死的话，凡是短到能迈两步的肢都踩不到地，错拍会自我抵消——实测一条 12.9 长的鼠腿
在 y=14 的髋位下 `reach=0`，直接掉出步态表。所以扫一遍 Δy 取"承重肢最多且伸展度最舒适"
的解，顺带得到这只兽是蹲伏还是撑起。

**相位由静态稳定解出来。** 肢体位置是随机挑的，可能一侧三条另一侧一条。约束是任一时刻
≥3 只脚着地、且**核心体积质心**（不对称的，x=−0.28 z=+1.47）的地面投影落在支撑多边形
内且有正余量。解不出来的基因组站不住，重采样——合法性归 `genome.validate`，站不站得住
归力学。

自检把这些全变成断言（`check_gait.py`）：摆频与解析解对拍 / **支撑相世界系不滑步**
（体坐标位移必须是 `stride×duty` 而非 `stride`，差一个 duty 因子就是每步都在蹭地，
初版就写错了）/ 不过伸 / 触地 / 支撑数 / 稳定余量 / 循环周期性 / 可复现 / 错拍率 ≥60%。

## 核心阶段动画：还没有腿的时候

缝合兽不是刷出来的成品——它先是一团核心，靠捡尸体一件件把部件长进去（正典那头幼兽只有
三条腿，第四条从野狗尸体上"借"来，花了约七日）。**无肢阶段是它必经的一段人生**，需要
一整套自己的动作，不能拿有腿的步态凑。

**蠕动和步态是同一条物理约束**：着地的那一段在世界系里必须静止，只是"脚"换成了身体的
"锚段"。双锚循环——相 A 后段锚地、前段前伸 d；相 B 前段锚地、后段跟上。净前进 d 是
**推出来的**。自检把每周期净位移加回去，验锚段世界位移为零（实测 0.0000 px）。

体积严格守恒：拉长时 `scale_xy ∝ √(L₀/L)`，实测波动 4.44e-16（机器精度）。

**爬得比走慢是算出来的**：`v_crawl = d × f`，而 `f = rate/(2d)`，所以 `v = rate/2`
——**只取决于组织收缩速率，与拉伸幅度无关**。算出 0.19 格/s，而有腿步态 0.56–1.10 格/s。
没捡到腿之前它又慢又脆，这就是它必须去捡尸体的原因；进化压力是算出来的，不是设定的。

**芽的几何按满尺寸建，当前生长度由 bone scale 表达**（休眠 0.10）。反过来做行不通：
Blockbench/GeckoLib 几何是静态的，缩放一个 0.44 半径的小疙瘩永远长不出东西，实测整条
嫁接动画看不见。运行时服务端直接驱动 `bud_<槽>` 的 scale，动画只是参考曲线。

**父骨的 R/S 会作用在子骨的位移上**（写形变动画必看，这坑踩了两次）。子骨写的 `pos`
会被父骨的旋转和缩放一起变换，所以「子骨位移 = 目标 − 父骨位移」这种加法补偿只在父骨
纯平移时成立。两次实测：蠕动中段拉伸 k=1.4 时 core_fore 凭空多跑 4.19px（锚段变蹭地）；
爆体里父骨同时鼓胀 scale 1.2 且翻滚，nodule_r 被父链放大到 −32px，落地钳制怎么调都拦
不住。**正解不做近似**，用父骨完整世界矩阵反解（`core_anim.place_world`）：

```
W_parent · (o + pos) = o_world_rest + offset   ⇒   pos = W_parent⁻¹·目标 − o
```

调用要按父先于子的顺序。还有一条附带的：父骨是谁得按**真实父骨**取——`nodule_r` 的父骨
是 `core_hind` 不是 `core_mid`，一律减 `core_mid` 会把它连同挂在它上面的芽甩到地下。

（不做这层桥接也不行：中段 z 缩放留在 1.0 时，前后段一分开，原本刻出来的凹槽会被拉宽
成可见裂缝——3/4 视角实测。）

七条动作各自的设计约束写在 `core_anim.py` 的 docstring 里，自检在 `check_core_anim.py`：
不滑步 / 净前进 / 体积守恒 / 循环接缝 / **各 lobe 异步搏动**（同步会读成"一只动物在喘"，
断言互相关 <0.85，实测 0.249）/ 嫁接单调且有停滞（匀速长大读成技能特效）/ 死亡逐 lobe
依次泄气且赘生物先瘪 / **扑击蓄放速度比 ≥2.5**（实测 ×10.8，恐惧的唯一来源）/
包裹张合幅度 ≥0.5 且咽下后主体变大（吃进去的得有去处，凭空消失是吞质量）/
受击回到静止 / 不穿地。

**何时从爬改成走，是推出来的**：`locomotion` 判定「够得着地的承重肢 ≥3」即可用步态，
否则只能蠕动。这条判据和基因组合法性、稳定性求解共用同一套几何，不是另外定的规则。

## 碎裂 / 分裂 / 繁殖：这东西怎么变成更多这东西

粘住这几团肉的只有那几道癒合痕。所以撑不住就沿最弱处裂开（分裂）、被打死就所有弱痕
同时崩（爆体）、碎片活下来捡尸体重新长成一只（繁殖）。

**从哪儿裂开不需要画**：癒合痕就是两个 lobe 的表面交界，交界体素数就是那道接合的
**面积**，也就是强度（`core.weld_areas`）。应力升高 = 逐条切断弱于阈值的接合，剩下的
连通分量就是碎片。同一只兽每次裂法一致、可复现。实测应力递增给出 1→2→3→4→6→7 块。

**碎片就是一只小兽**：它带走覆盖的挂载点，也就带走那些肢体，于是逃窜步态**直接走
`locomotion.solve()`**——够得着地的承重肢 ≥3 就跑步态，不够就蠕动爬。「不同部位往不同
方向逃窜」不是特效，是每块碎片各自解出来的。

**逃窜速度必须互不相同**，否则只剩方向不同。尺寸无关的量是**应变率**不是绝对收缩速度，
所以 `v_crawl = 应变率 × 体长 / 2` **正比于体长**：大块爬得快、小碎片爬得慢。实测四块
碎片 0.060 / 0.082 / 0.114 / 0.122 格/s。

**健康分裂是最小割**：撕开要切断跨越裂面的**所有**接合，不是一条。初版只枚举单条边，
7 个 lobe 的接合图连得密，删一条几乎断不开，永远报"无可行切面"——那不是它分不了，是
模型问错了问题。改暴力枚举全部二分（64 种），要求两侧各自连通且质量达标，取割最小的。

**质量必须摊得开**：`core_mid` 曾占全身 45%，爆体时只有主体活得下来，「各部位分头逃窜」
根本不成立。摊平后最大一团 28.3%、四团过存活线。自检卡 ≤34%。

`check_fission.py` 八项：质量摊平 / 应力单调（应力升高不该让它重新粘上）/ 质量守恒 /
**动量守恒**（Σmᵢvᵢ=0，不守恒就读成"被炸飞"而非"自己崩开"）/ 逃窜异速 / 最小割分裂 /
繁殖闭合（碎片基因组是亲代真子集，肢体不漏不重）/ 爆体确实散开。

## 碎片模型：撕下来的那块自己是什么

**不是把核心等比缩小。** 三件事必须重算，全部从既有的场里推：

**创面**——少了另一半，母体身上原本埋在内部的体素就成了表面（`core.surface_of` 按 lobe
子集重跑表层判据）。哪几格是创面也是推的：缺失的邻居在母体里是实心的，肉原来就在那儿。
断口的法向取**缺失邻居方向**而不是场梯度（场在体内光滑，−∇f 在断口指向随机），材质另起
一张表（断口露的是内部组织，不该有黏液也不该有膜），抖动幅度 ×1.9（皮是长平的，断口
是扯出来的）。

**重新分节**——只带一团肉的碎片是一块刚体，而蠕动要两个锚轮流抓地，一根骨做不到。所以
沿爬行方向按**质量**三等分（按长度分会在两端切出两三格的薄片）。爬行方向同样是推的：
带头槽的朝头槽法向（将来的前端），没带头槽的朝**背离母体**的方向（断口在身后）。

**组织预算**——芽的料不是凭空来的。`core.graft_budget` 从正典"一次一条、每条七日"反推出
同时能持有的未分化组织量；碎片按质量比缩，于是它**长不出母体那样的触手**。这就是它非去
捡尸不可的理由，是体积算出来的，不是设定的。

一样母体有而它没有的：**癒合痕**。只带一团肉的碎片一道痕都没有——痕是两块组织长到一起
的记号，它只有一块。缝合兽不是生下来就缝合的，那身痕是它一辈子吞下去的账。

**分裂要付代价**：骑在裂面上的挂载点会被撕坏（那片皮一半跟着另一半走了），两边谁也带不
走。所以分出去的两半加起来比母体少几个槽，少的正好在裂面上（实测健康分裂丢 1 个、
爆体丢 3 个）。`check_fission` 的繁殖闭合相应改成"掉肢只允许掉在被毁的槽上"。

碎片动画（`fragment_anim.py`）用的是和母体**同一套约束**，只是身体换了：行程 = 自己的
锚段间距 × STRETCH，频率与体长无关，于是速度正比于锚段间距——`core_fore` 那块锚段只隔
5.0px、母体隔 21px，它只能爬 0.045 格/s（母体 0.188）。**它跑不掉**，所以它得躲、得等。

## 触手：生长与乱抽

**每个挂载点一条生长动画**（`graft_<槽>`，17 条），时长各不相同：组织合成速率是整只兽的
代谢常数，所以长一条芽要多久**正比于这条芽的用料**（`core.bud_tissue` 算并集减去埋在体内
的部分——按包围盒相加会高估一倍以上）。实测 0.50–3.21s、17 个各不相同的值。下限 0.50s
是可读性的物理下限（五段推进/停滞 × 每段至少两 tick），`vest_dr` 按用料算出来只有 0.11s。

**每条芽是一条骨链**（四节各一根骨），不是一根骨。整条绑一根骨时它只能绕根部倾倒，
末节与根节永远共线——渲出来是机械的。改成骨链之后，四节**各自被驱动**：

- 每节的抽搐节律走同一条速度上限，力臂换成「这一节以外那一截」的长度，于是根部约
  3 下/循环、梢部约 8 下（顶到 `FLICK_MAX_HZ`）
- 每节有自己的方向序列与发火图案（按 (槽, 节) 取），所以整条不是圆弧也不是鞭子，
  是一条不断改形的 S
- 每节有**常驻漂移**：不发火的时候也在按自己的节律慢慢晃。只在发火瞬间动、其余时间
  冻住，眼睛立刻读成机械臂——自检直接量"最长静止段"，要求为 0

先写过"根部驱动、每节滞后四分之一周期"的鞭子模型，**不成立**：这些节的自然摆频只有
0.7–2.4 Hz，而抽搐在 5 Hz 以上，远高于共振点，"末端跟着根部甩"根本不适用；实测滞后
累积到 0.99 秒，比整条循环还长。正解来自正典——**这东西没有神经**，没有沿肢体传导的
激活波，每节只能被局部激发，本来就不该协调。

**乱抽**（`core_thrash`）：每个挂载点同时冒出一小截，各自急抽。三条主张，逐条量：

- **抽多快有上界**：没有哪个部位能比它扑击时更快，于是 `f ≤ V_max·ATTACK/(摆角×力臂)`。
  力臂就是那条芽伸出去多长，所以短茬甩得快——和肢体的复摆律（`f ∝ 1/√L`）同源，只是这里
  被速度封顶而不是被重力回复，指数是 `1/L`。
- **茬只能是短的**：同一份组织预算摊到 17 个槽上，骨缩放只有 0.42。全身长满触手它负担不
  起。而短茬力臂小、抽得更急——"又短又急"是同一个预算推出来的两件事。摊出去的料从自己
  身上抽，本体等体积缩小（自检断言芽增 = 本体减，实测 452 px³ 对 452 px³）。
- **集体找不出节律**：这条**不是**靠频率散开的。17 个槽 girth 大多挤在 3.2–4.0，力臂跟着
  挤，算出来的次数集中在 5 上下（拉长循环也没用，实测四档下不同值只有 4/4/5/6 个）。
  相位均匀铺开也救不了——同频信号相邻相位只差周期的十五分之一，5Hz 下就是 12 毫秒，眼睛
  看到的是一圈茬依次抽过去的**行波**。真正管用的是**每一拍发不发各自决定**：痉挛本来就不
  是节拍器。加上这一条之后两两轨迹互相关从 0.90 掉到 0.47。改骨链之后常驻漂移又把它顶
  回 0.61——因为整数周期约束把 0.66–2.39 Hz 全压成 1 或 2 个周期，十七条同频、随机相位
  必然撞上（只留漂移时实测 0.970）。所以漂移的周期数与相位也改成构造的：周期数按节序
  递增，相位按槽序在循环里均匀铺开。

载体在乱抽时**一动不动**——一堆东西在抽而载体是静的才瘆人，跟着一起晃就读成"整只在抖"。

芽的形状为此改过：原来三节、末节收到根部的 0.50，乱抽渲出来每条都像贴在皮上的鳞片；
改四节、收到 0.28、长细比 2.7:1 → 3.4:1 之后才读得出"一根"。

## 部件层·肢体：一条捡来的腿在这具身体上会长成什么样

基因组只留下两样信息：这条肢的**节段长度**，和它从哪只野兽身上拆的。**"它原来多粗"
这个数字压根不存在于流水线里**——每一节多粗、怎么弯、脚掌多大、哪一段还看得出原主人，
全部由这具身体的重量和这条肢在站姿里的位置算出来。

**载荷不能按条数平摊。** 三点着地时竖直反力是**静定**的（ΣF=W + 绕两轴力矩为零，
三个未知数三个方程），多于三点则解非负最小范数。结论和平摊完全相反：**扛重的是短腿，
长腿在扶着**——缩在质心下面的 13 px 腹肢独扛 71% 体重，远远撑出去的 42 px 蛛足只分到
26%。支撑相内的峰值再乘 π/2（半正弦的峰均比，推出来的不是拍的安全余量）。

> 用"先取最小范数解、见负就剔"的贪心会算出 111% 体重压在一条腿上：剔掉一只脚会改变
> 支撑多边形，剩下三点可能已经包不住质心。脚数 ≤6，直接枚举全部支撑子集最短也最不会错。

**姿态是"最省肌肉的那个折法"。** 折到够着落点有无穷多解，选哪个不该我挑：动物站着不动
时采取的是让抗重力肌出力最小的姿态，因为那份力要一直出下去。目标函数 Σd_j/a_j 把关节
往载荷线上挪。留给供体的只剩**折的方向**（兽腿膝前肘后逐节交替、禽腿的"反折膝"其实是踝、
蛛足先抬后落），幅度是算的。先前用一组手挑的折叠权重，折出来的关节忽左忽右，肌肉截面
跟着忽粗忽细，渲出来是一串珠子。

**粗细：骨由弯曲定，肉由肌肉截面定。** 三条失效判据（轴压/屈曲/弯曲）里弯曲永远主导——
腿是被掰断的不是被压扁的。肌腹长在关节近端那一节上，更远的关节只有腱穿过（腱强两百倍），
**上粗下细因此是省力的结果而不是造型偏好**。根部那一节还要额外背上嫁接关节自己的肌肉：
脊椎动物把髋伸肌放在骨盆上，而这东西的核心是个没有骨架的肉囊，锚不住任何东西。

**由此掉出来一条最刺眼的结论：蛛足要的肌肉这具身体给不起。** 它基节只有 2.5 px、肌肉
力臂小得可怜，同时腿最长、地面反力力矩最大，算出来根部需求 9–19 px（兽腿只要 4–9 px）。
而肌腹粗不过基节长度的一半 ⇒ **96% 的驱动肌只能塞在体腔里**，外面看这条蛛足反而是细的，
鼓起来的是它旁边那团核心。捡到蛛足是坏事，这是算出来的。

**材质分界也是算的**：一节的横截面里本体新长的肌腹与供体原有的骨+腱谁占多数，外面就露谁。
于是**脚永远是别人的**（那一节按定义没有肌腹）——玩家一眼看出供体物种，靠的是脚那一截。

**闲肢分三种，各有各的平衡解**：不承重的肢粗细由**组织预算**定（`core.graft_budget`，
和芽同一份料），于是同样一份料摊成 36 px 的细绳或缩成 6.9 px 的肉疙瘩；有骨的死腿是
自由铰，平衡姿态是第一个关节硬折后每节笔直向下；无骨的触手是连续软梁，按悬臂自重挠度
θ = 2ρgL³/(3Er²) 逐节弯；垂到地面的就**摊在地上拖着**。

### 从骨骼做起：十五副骨架，四类站姿

第一版只有"哺乳类/禽类/蛛类"三张节段模板，狼腿羊腿猪腿是同一组比例乘一个体型系数。
渲出来六条腿一个剪影——**"这棍子是什么腿，看不出来"**（用户实测）。问题不在粗细算错，
在于流水线里区分物种的信息只有"总长"这一个标量，而它被载荷推出来的粗细盖过去了。

重做的口径是**先有骨架**：每个供体物种一副真骨架（股骨:胫骨:掌骨:趾骨 的实测比例），
再由**站姿类别**决定哪几根骨着地——这一层才是剪影的分水岭：

| 站姿 | 谁 | 掌骨倾角 | 读出来是什么 |
|------|----|---------|------------|
| 蹄行 unguligrade | 羊 / 山羊 / 牛 / 猪 | 80° | 小腿以下一根竖直的管骨 + 一枚劈开的蹄 |
| 趾行 digitigrade | 狼 / 狐 / 兔 / 鸡 / 鹅 / 鹫 | 52° | 脚跟吊在半空——**狼那个"后弯的膝"其实是踝** |
| 跖行 plantigrade | 人 / 鼠 | 22° | 整片脚掌拍在地上，脚后跟向后支出来一块 |
| 外展 sprawling | 三种蛛 | 62° | 先把腿节抬到身体之上再斜插下去，钩尖点地 |

**脚不再是链的末端**：最后一两根骨归站姿摆放，IK 只解到踝。上一版把脚也一起 IK，于是
"脚"只是两根越来越细的杆，狼爪羊蹄人足全一个样。现在偶蹄劈成两瓣、肉垫是掌垫加三趾
带爪、人足有脚跟和脚趾、禽爪三前一后、蛛钩下面摊一片甲板——**接触面积仍恒等于
载荷/承载力**，只是分配进各自的形状里。

**体表只有长毛的才加几何**：MC 这个尺度上"毛茸茸"读的是轮廓，光调颜色还是一根光柱子。
但**随机撒小方块出来的是碎石不是毛**（第一版实测，用户评价"好乱，没有规律"）。毛有两条
真实结构，缺哪条都不像：① **有毛流**——每一根顺着肢体往远端躺、外加一点翘起才离得开皮，
所以出的是沿轴向的短柱不是方块；② **成排交错**——一圈一圈往下排，相邻两圈错开半个间距
像瓦片互相压住，规律感来自这里，随机只负责让它不呆板。兽毛细密一直盖到掌骨、羊毛又粗又
密结成团、猪鬃又稀又硬又长、禽的覆羽只到大腿（跗跖骨是裸鳞）。鳞/甲/皮/裸靠材质本身就够。

**缝上去的疤也是算出来的**，两处各有来历：接合痕在挂载点那一圈；**交界痕在本体新肉与
供体组织的分界上**——那个分界材质表已经算过（`Limb.mats` 里 graft 变成 hide/scute 的那
一节），肉长到哪儿为止痕就在哪儿。做法沿用核心那身癒合痕的读法：不是外科缝合，粗细逐段
变、约一成断开、偶尔堆一个肉瘤——等粗等距的环会立刻读成焊接件。

单条腿认不认得出**只能单件看**（仓库的分部件纪律）：`--gallery` 按站姿分四张并排出图，
每条同载荷同姿态，差别全部来自骨架与站姿本身。

### 肉是一整条连续的包络，不是一节一个粗细

用户第二轮的话：**"看着应该没安装上肌肉和皮肤吧"**。看图确实如此，而且不是观感问题，
是模型里真缺东西：

1. **远端几节的渲染半径恰好等于骨半径**，也就是把骨头直接画在外面。力学只解"某样东西
   必须扛住某个力"，而腱鞘、筋膜、皮下、血管、皮这几层不扛主要载荷——力矩归零它们不会
   跟着消失，模型里却没有它们的位置。补一条下限：远端肢外径 ≈ 骨径的两倍
   （`SOFT_OVER_BONE`）。**这条不是推出来的，是量出来的**（马的管骨 ø35 mm，整个管部
   连屈腱带皮 ø70–80 mm；狼、禽的跗跖同量级），所以单独标出来，不混进上面那些解出来的数。
2. **粗细在关节处跳变**：每节渲成一根等粗柱子，于是大腿 4.8 px 直接接上小腿 0.5 px。
   肉是连续的——肌腹**不跨关节**，所以关节那一圈最细，且两侧必须取同一个值；肌腹的鼓包
   峰值偏**近端**（约 38%），两端收进腱里。现在沿节采样这条包络（`Limb.profile`），
   渲出来是小腿肚在上、跟腱在下，不是一根均匀的棒。

**皮不在这个厚度里。** 1 px = 6.25 cm，兽皮 2–5 mm 连十分之一像素都不到——皮在这个尺度
上不是厚度，是**表面**。加粗一像素来"表示有皮"是假的；皮只能靠材质和**裂口**表达。

### 裂口：方向是拉出来的

裂缝一律**垂直于把它拉开的方向**，于是同一条腿上两族裂缝互相垂直（自检 ⑫ 卡的就是这个，
撒歪了会红）：

- **关节横裂**——关节要屈伸，伸侧的皮必须跟着这段弧长伸缩，拉伸方向沿肢轴 ⇒ 缝横着开。
  折得越死裂得越多，条数直接取自站姿里的实际折角。大象犀牛的关节皱、人的指节纹都是横的。
- **角质纵裂**——蹄/爪/甲是管状角质，失水收缩加上着地时管壁向外张，拉的是**周向** ⇒
  缝顺着生长方向竖着开。马蹄的裂蹄（quarter crack）就是竖的。

### 脚掌以内不能按点接触算

包络下限一加，一个旧错误立刻顶了出来：人足的**趾骨比掌骨还粗**（0.51 vs 0.41 px），
末节反倒成了最粗的一节，自检直接红。根因是把地面反力缩成一个点——对脚掌**以内**的骨头
那是假杠杆：脚掌是一片有长度的接触面（`pad`），一根趾骨只撬得动它远端那一小片的力。
改成按分布压强积分（份额 × 形心距）后趾骨掉到掌骨以下，末节重新是最细的一节。
**踝以上不受影响**：整片脚掌都在它的远端，力矩仍旧是全载荷乘到形心的距离。

顺带回答"我好像没看见人腿"——它一直在（seed 5 的左后腿就是人腿），只是读不出来。这个
尺度上人腿的辨识全在脚上：三枚等大的趾是"某种爪"，**五枚递减的趾**才是人。现在按真实
比例出五趾（拇趾最粗、第二趾最长），配上跟骨支出去那一块，跖行才认得出来。

### 跟不在链上，但它必须被画出来

单件看人腿时（`HumanLeg` 三视图）露出一个更硬的错：**整只脚画在了踝的前面**。链上只有
`[踝, 跖球, 趾尖]`，渲染又把 `j[-2]`（其实是跖球）当成跟来用，于是脚底从跖球起步一路铺
到趾尖之外。实测那条腿踝的地面投影在 z=+1.75、地面反力作用点在 z=0，而画出来的脚底是
−2.95…−7.55——**连受力点都没盖住**，看上去像用前脚掌的位置支着一根杆。

跟不在链上是对的：**跟骨和掌骨是同一块刚体**，不是一节，硬塞进链里会多出一个假关节。
所以另开 `foot_heel()` 把它单独取回来（跖行专有，其余站姿返回 None），渲染时补两件东西：
跟到跖球的整片脚底、以及踝正下方那一坨**跗骨块**（没有它，踝和脚底之间隔着一段空的，
整条腿像插在脚上而不是站在脚上）。修完踝正好落在跟→跖球的 **25%** 处——真人也是这个位置。

自检 ⑬ 把这条焊死：**跖行的脚必须托住踝**（踝的地面投影落在跟与跖球之间）。"跖行"这个
词的定义就是整片脚底承重、踝压在脚底上方；踝投影跑到脚底外面，那条腿就是踩着前脚掌站的。

### 折弯平面由铰链轴定，不由落点定

同一张单件图还露出更深一层的错：**大腿在小腿的正侧面**——腿是朝侧面折的。

上一版 `stand_pose` 把折弯平面取成"髋与落点所构成的**竖直面**"。腿在身体正下方时这没问题
（那个面正好是前后向的），但缝合兽的挂载点长在核心四面八方，脚一落到侧面，那个面就变成了
**冠状面**，膝跟着朝侧面折。而脚本身永远是朝前的（`foot_chain` 用全局前后轴），于是膝的
折向和脚的朝向**互相垂直**——那不是兽腿，那是蛛足的折法。

正确的约束来自关节本身：膝是**横轴铰链**，只能在含前后方向的平面里折。脚要落到侧面去，
靠的是髋（球窝关节）把整条腿**外展**出去，膝依旧朝前——真狗真牛站得再开也是这样。所以
平面 = 张成(髋→踝, 前后方向)：既穿过落点（不然够不着），又让膝朝前。外展类（蛛足）保留
原样，它的参考方向是**正上方**（先把腿节抬到身体之上再落下去），那正是"外展"的定义。

改完顺带掉出两处旧账：

- **代价函数把力臂量到了踝，而不是量到地面反力的作用点。** 这两个点不是一回事——链解到
  踝，而踝在落点后面（趾行退 0.62 个掌骨长）。拿踝当受力点，"最省肌肉"的解就一路把膝往后
  推：实测**所有**兽腿都被判成"往后折更省力"并触发改折向，膝全朝后。改量到落点之后，
  九个物种全部膝朝前、全部不再需要改折向。顺带整条腿的肌肉需求掉了一大截（关节真正压到了
  载荷线上），`check_limbs` 的"舒适伸展省下多少"从 35% 涨到 37%。
- **`BEND` 表的符号与它自己的注释相反。** 表里禽和蛛的第一个符号，按新约定（`+` = 朝参考
  方向鼓出）读出来是"禽膝朝后、蛛腿节朝下"，跟注释写的"反折的是踝""先抬到身体之上"正好
  反着。表现就是每一条禽腿蛛足都被力学解翻回来、永远挂着"被迫改折向"。力学与注释一致、
  只有表跟它们不一致 ⇒ 是表错了，按约定改正。

自检 ⑭ 卡的是**折弯平面必须含前后方向**（平面法向 ⊥ 前后，实测 12 只兽全部 0.000）。
一开始写的是"膝的侧向偏移要小于前后偏移"，那条是错的：一条往斜后方伸出去的腿
（seed 10 的兔腿，髋→踝 = (+0.60,−0.22,+0.77)），平面里那条垂线本来就带很大的侧向分量
（+4.40），可平面照样含前后、膝照样朝前——按侧向大小卡会把正确的腿判红。

### 顺带修掉的运动层三处真错

落点原本推到**可达极限**（`reach`），而同一层的 `solve_ride_height` 通篇在把伸展度往
`COMFORT=0.72` 上凑——两处对同一个词的用法是矛盾的。撑到极限的代价不在运动层而在这里：
力矩正比于关节到落点的水平距离，实测根部要粗到两倍（Σ根部 46.8 → 31.5 px，省 33%）。
而收窄**不换稳定性**：把落点收到极限的一半，全周期最小余量从 +3.26 只掉到 +3.13，
seed 3 反而从 +0.52 涨到 +0.66——支撑多边形是绕各自的髋收缩的，质心本来就在中间。

改完 `check_gait.py` 从 10/12 变成 **12/12**：原先记在这份 README「已知红项」里的
`seed=5` 采不到能站的兽，以及 seed 12，都因为可行姿态空间变大而站得住了。

> 判据必须用**相位优化之后**的余量。第一版拿 `feasible`（全着地的上界）当判据，
> seed 12 保住了上界却在摆动相塌掉，从"能站"变成"站不住"。现在先窄后宽各解一次相位，
> 取好的那个。

**第二处：腿连到踝，不连到地面。** 可达半径原本按"髋高 vs 总长"算勾股，但蹄行动物的
踝抬到掌骨全长那么高（羊/牛的管骨），那一截长度是竖着用掉的，不能折算成水平可达。
按老算法摆出来的羊腿股骨横着支出去，像条断腿（腿谱实测）。

**第三处：踝还往身后退一截。** 掌骨向后倾多少，踝就在落点后面多少（趾行退 0.62 个掌骨
长）。摆落点时要解的是"落点摆在哪、踝正好落在舒适距离上"，那是个二次方程。两条更简单
的写法都试过都不行：忽略它 ⇒ 腿够不着自己的踝、IK 无解退回直链、关节落到地面以下
（y=−4.13）；把落点整体前移 ⇒ 支撑多边形跟着前移、质心落到多边形外，seed 12 站不住。

## 部件层·头颅：这颗头原来是拿来吃什么的

肢体层问的是"这条腿要扛住多少力"。头颅层问的是另一个问题——**这颗头原来是拿来吃什么
的**。头骨是一台取食机器，它每一处形状都是某个取食动作留下的痕迹；把痕迹算出来，狼头
就自己长成狼头，牛头就自己长成牛头，一张"狼头长这样"的表都不需要。

### 先记一条被推翻的总纲

初版写的是：1 px = 6.25 cm，脸上的软组织只有 5–15 mm，连四分之一像素都不到，所以
「一颗头 = 它的头骨 + 它的咀嚼肌」。据此把毛、唇、鼻头、眼睑全删了，只把颅骨、颧弓、
下颌和常年露在外面的犬齿逐块涂色画出来。用户看一眼就问：**"你这是什么头颅？是头骨吗？"**
——是的，那就是头骨，解剖标本的画法。

错在一个没查的换算：**6.25 cm/px 是这只兽的世界尺度，不是头的尺度。** 头是被养大过的
（px_per_m = 模板长 ÷ 供体真实头长），按供体自己量 1 px 只值 0.6–4.6 cm：

| 供体 | 1 px 相当于供体身上 | 头上的毛 | 折合 px |
|---|---|---|---|
| 兔 | 1.3 cm | 1.0 cm | 0.77 |
| 狐 | 1.7 cm | 1.5 cm | 0.90 |
| 羊 | 3.3 cm | 2.5 cm | 0.75 |
| 狼 | 2.5 cm | 1.5 cm | 0.59 |
| 牛 | 4.6 cm | 0.8 cm | 0.17 |

那句"看不见"错了 2.5–10 倍。改过来之后的总纲是

> **一颗头 = 它的头骨 + 它的咀嚼肌 + 绷在外面的那层皮毛**

前两项决定**形状**，第三项决定**能不能读成一只活兽**。推导照旧全落在头骨与肌肉上（凡是
算出来的都直接是看得见的形状：推出"这块咬肌要 167 cm² 横截面"，那就是渲出来的那块腮
帮子），渲染时整个头骨按体表厚度外扩一圈、统一涂成供体自己的皮毛，眼/鼻/唇/角/露在外面
的齿再长到毛的外面。**嘴默认是闭着的**——活兽闭嘴时能看见的只有一道唇缝；露在外面的齿
是例外，条件是终生生长（啮齿门齿、猪獠牙）或齿冠长过唇厚。狼的犬齿冠算出 1.1 px、唇厚
0.9 px，露 0.2 px，在模型精度以下——所以它闭着嘴时看不见牙，真狼也是这样。

毛厚这一列是**观察值**，不是推的，理由写在 `coat_px` 里：按热平衡推过一遍（d = k·ΔT·
体表面积/产热），狼解出 2.0 cm（实测 3）、兔 2.7（实测 2.5）都对得上，但**鼠解出 3.2 而
实测 0.5、牛解出 7.7 而实测 1.2**，两头都错六倍且方向相反——小兽根本不靠毛保温（钻洞 +
抬高单位质量代谢），大兽的问题是散热不是保温。毛厚由气候与行为主导，硬推等于编一个假
的因果。

**脑颅用实测脑重，不用异速式。** 脑重按 M^0.74 涨而头骨长按 M^0.33 涨，所以体型越大
脑颅占脸的比例越小——鼠 43%、兔 41%、狼 29%、猪 22%、牛 20%，剩下的全是脸。这一条单独
就把"小兽头圆、大兽头长"分开了。但牛的脑比哺乳类均值小一半以上，套均值算出来的牛脑颅
会大出三成、脸跟着短掉，牛头读成鹿头，所以这一列走实测。

**咬合力 = 食物断裂应力 × 咬合接触面积。** 方向是这个方向：不是"想咬多大力"，是"把这口
东西弄断需要多大应力乘多大面积"。牙的全部本事是把力集中到刃和棱上，量出来各种咬合模式
的接触面都落在臼齿宽平方的 0.2–0.3 倍——**真正分开食肉与食草的不是接触形状，是同时咬
几颗牙**：剪/压/啃/吞永远只有一颗牙受力，磨却是一整段齿列同时受力（单侧咀嚼，两三颗）。
于是牛的绝对咬合力（1857 N）大于狼（1201 N），而狼在裂齿那条刃上的应力远高于牛——
两件事同时成立，这正是"力"与"应力"的区别。实测口径：狼 1.2–1.5 kN、牛 2–3 kN、
猪 ~2 kN、鸡 30–50 N。

**颌关节的高度是磨与剪的分水岭，而且它是算出来的。** 下颌绕关节转 θ 时，齿列除了张开
还会沿前后向滑 θ·h（h = 关节高出咬合面多少）。磨牙的一个冲程要扫过一整颗臼齿的宽度
⇒ **h = 齿宽 / θ**。牛按这条算出关节高出咬合面 12 cm，实测 10–12 cm。剪切类必须 h = 0：
滑动会把刃磨钝，而且关节在剪切时只能受压不能被撬开。

**骨头往哪长是个极值问题，解出来正好是矢状嵴。** 颞肌截面要塞进脑颅与颧弓之间的窝里，
高和厚都自由，于是 min(嵴高 + λ·外张) s.t. 高×厚 = 截面积。**λ 不是 1**：矢状嵴是一片
薄骨，而颧弓外张要把整个头加宽、弓本身还得更粗才拉得住咬肌，取 λ=3 ⇒ 窝是竖长的，
高 = √(3A)、厚 = √(A/3)。脑颅已经够高就不长嵴，不够的差额才长成嵴——**狼有嵴（1.5 cm，
实测 1.5 cm）、牛几乎没有**，是这条极值解算出来的。取 λ=1 会解出正方形的窝，狼的颧弓
被顶到离脑颅 4.2 cm（实测 1.5 cm），整颗头宽出一半。

**眼位由"捕食还是被捕食"唯一确定。** 捕食者在咬中的那一瞬间猎物就在吻端，双眼都得看得
见它 ⇒ 重叠角 = 2·atan(猎物半径 / 头长)，猎物半径由"一口吃多大"反推。被捕食者的目标
不是看清而是身后不留盲区 ⇒ 单眼视野 + 2φ = 360°。狼算出 φ=50.6°、重叠 54°、身后盲区
104°；羊算出 φ=82.5°、无盲区、正前方还剩 30° 重叠——实测狼 ~50°、食草兽正前方确实还有
约 30° 的双眼区。（单眼视野本身两类不同，155° vs 195°：被捕食者的视网膜包得更靠后。）

**兔耳大是热力学，不是造型特征。** 耳廓面积 = 那一份代谢产热 / (对流系数 × 温差)。兔子
不会喘息、不出汗，只能拿耳朵当散热片，算出来 10.1 × 5.9 cm，实测家兔 11 × 6 cm。牛会
喘息还出汗，那一份低得多，可它体重六百公斤，绝对产热压过一切，算出 26 cm（实测 25）。
**十种供体里没有一种是被"拢声漏斗"的下限卡住的**——耳朵大小是热力学问题，听觉只定形状
与朝向。

**角不是梁，是溃缩区——这一条是算出来才知道的。** 先按抗弯算了一遍：公羊对撞峰值
3.5 kN、力臂 0.19 m，解出基部半径 2.2 cm，代回去应力只有 19 MPa，是角质强度的七分之一。
也就是说按"别掰断"来设计，角可以细得像根筷子；可实测公羊角基直径 10 cm 以上。真正的
约束是**能量**：对撞动能必须在颅骨之前被吃掉。角是一段工作在弹性范围内的角质，体积 =
那一半动能 / 储能密度。**卷曲也是推的**——角质在基部成环沉积，外侧比内侧长得快、比值
固定 ⇒ 曲率 κ = (1−k)/d，而 d 向尖端收细 ⇒ 越靠尖卷得越紧，正是对数螺线。盘羊按这条
算出 1.5 圈（实测 1–1.25）、山羊 100°、牛 11°。两条判据并排列在报表里，储能要的半径是
抗弯的 **1.9–4.0 倍**——角越短这个比越大，因为同样一份动能要塞进更短的一段里。

**算出来比渲染下限还薄的东西整块不画，而不是撑到下限。** 撑是撒谎：鸡的颊肌算出来单侧
只有 0.23 px，撑到 0.5 px 之后两侧加起来占掉 2.9 px 宽的头的七成——推导说"这只兽的腮
不鼓"，画出来却是满脸腮。于是鸡和蛙的两块咀嚼肌整块消失（禽与两栖类的颌肌本来就小），
而结构件（脑颅/脸/下颌/癒合环/眼/耳/角/喙）不适用这条：它们缺了就不成其为头。

> **额区必须单列，不能并进吻里。** 脑腔只装脑，而脑腔前缘到眶前缘那一段装的是颞窝、
> 眶和鼻腔后段——它属于颅。round 1 把它算进吻，狼的口鼻占掉头长的七成（实测约五成半），
> 整颗头读成一根管。

> **吻的宽由鼻腔撑，不由齿列撑。** round 1 拿"鼻腔截面 ÷ 脸宽"当深度、脸宽另由齿列定，
> 结果狼的吻只有 1.16 px 宽而 2.6 px 深，渲出来是一块竖着的板。改成鼻腔截面取方、宽与
> 深同一个数之后，狼算出边长 4.2 cm、牛 12.3 cm（实测 4–5 cm 与 ~12 cm）；齿列退回去
> 只当宽度的下限。

### 碰撞检测：旧的那条判据什么都没在看

用户问"这个头是不是堆叠在一起了"。量了一遍——**12 只兽里 17 处穿插超过半格，最深
4.35 px**：角穿过另一颗头的癒合环、耳朵插进隔壁的脑颅、两对角互相穿过，而最严重的一批
其实是**腿穿腿**。旧的那条自检比的是"两个挂载点之间的直线距离"乘一个 0.6 的宽容系数，
从头到尾没碰过真几何，所以全部放过。

现在按渲染出来的**体**逐对算：每块近似成胶囊（轴 + 两个半尺寸的几何平均），两轴求最短
距离，重叠 = 半径和 − 距离，超过 0.75 px 判红。三处修复：

- **癒合区豁免按"离表皮多远"算，不按根部半径算。** 这东西是几团肉长到一起的，贴着躯干
  那一圈两条肢的肉本来就该连成一片；但"贴着"的尺度不是根部半径——肌腹被埋进体腔的肢
  根部反而最细（腹肢实测根粗 1.0 而中段 3.2）。改用"接触点离表皮 < 两处肉厚之和"。
  两类的差别干净得出奇：一对的接触点离表皮 **+1.38 px** 而两半径和 4.38（融合），另一对
  **+25.88 px**（半空中交叉，货真价实的穿模）。
- **头挤在一起就互相顶开，并从表皮上坐起来。** 朝向本来取挂载点法向，可两颗头挨着长时
  法向不保证不打架。顶开的方向取**接触点**相对各自枕髁的方位，不是两个枕髁的连线——
  打架的常常是伸出去的角和耳，沿枕髁连线推根本推不到它们身上（实测一只耳插进隔壁的角
  里，按枕髁连线推了十二轮还剩 1.42 px）。另外头贴着弯曲的表皮放，比枕髁宽的部位必然
  陷进核心，所以解出一个**最小基座高度**让它坐起来，癒合环随之加长把那一段填上。
- **姿态求解器学会躲邻居，落点不够宽就掰开。** "别折进核心"与"别折进邻居"是同一条约束
  的两半；少了后者，省力的解会毫不犹豫把小腿折进旁边那条腿里，因为在它的目标函数里
  那块空间是免费的。但只加罚项不够——**落点是 `locomotion` 定的，那一层不知道腿有多粗**：
  最坏的一对挂载点相距 8.6 px、落点相距 8.8 px，而两条腿的中段各有 3.2 与 3.4 px 粗，
  需要 6.6 px 净空，怎么折都要穿。所以解完一轮拿到粗细之后，把打架那一对的落点在地平面
  上**平移**掰开（不是旋转：腹肢的落点就在髋正下方，力臂 0.0，转多少度都不动），夹回
  各自的可达半径，重新量静态稳定余量——掉得太多就退回原样，把这一对留给自检去报。
  **宁可报出来，也不要为了让自检变绿把兽摆成站不住的。** 贪心还得带一条守卫：掰开一对
  会把所有腿重解，完全可能把另一对挤得更死（实测一只兽因此从 2.65 px 恶化到 5.82 px），
  所以只有**全局最深的那处真的变浅了**才收下这一步。
- **姿态层调权重是死路。** 加了避让之后，两只兽的膝盖转头扎进了核心（f=1.41）——
  求解器在"穿邻居"和"穿自己身体"之间挑便宜的那个。往两个方向都试过：给核心 2.5 倍
  权重 ⇒ 互穿从 0 反弹回 4.24 px；给避让罚项封顶 ⇒ 同样反弹。**两条罚项争的是同一个
  无解的局面，谁重谁就全赢，调权重只是在两种错之间搬家。** 记在这里是因为它值一条
  教训：能动的自由度是落点，不是权重。
- **垂肢也得躲。** 全部十二只里最深的一处（5.82 px）是一条**不承重的垂肢**从旁边那条
  承重腿的中段里穿过去——避让和掰落点都作用不到它身上，因为它根本不在步态里：它没有
  落点、不参与承重，姿态是按自重挂下来的。`hang_pose` 本来就有一条"垂下去撞到自己身体
  就贴着滑开"，把邻居接进同一条即可：死腿挂在别的东西上会滑开，和贴着身体滑下去是同
  一件事。

**多头是这只兽唯一真正的便宜。** 几颗朝向不同的头拼起来，水平视野覆盖能接近全周——那是
基因组随机装配涌现出来的属性，不是设计的，所以 `gen_beast` 把它当一行数据报出来。

> **模板里的头高与头宽从此不是输入，是预测。** 尺寸只由 `HEAD_TEMPLATES` 的**长度**
> × scale 定，其余全部由力学在**供体的真实尺度**上算出比例，最后按
> px_per_m = 模板长 / 供体真实头长 一次性换算。报表把推出来的高宽和模板值并排列出来
> 对拍——十种全部窄于模板四成上下，说明那两列原本就是方块化的估值。

## 已知局限

- 顶视轮廓仍偏矩形——体素网格轴对齐的固有代价，靠抖动和跨度上限只能缓解不能消除。
- 「几只野兽融成一只」这个读法现在由头与肢共同承担；癒合痕退回它本来的角色（旧的
  这条限制已解除）。
- 挂载点的 `girth` 目前区分度窄（3.7–4.1），赘生物上的槽还没被真正卡住——等部件层
  有粗细不同的真实部件时才知道这个量够不够用。
- 步态只解了**直线行走**：转向、起步/刹停、被击退、爬坡都还没有。
- 稳定性判据是**静态**的（质心投影必须始终在支撑多边形内）。真实动物奔跑时是动态平衡，
  允许短暂失稳；沿用静态判据会让奔跑步态偏保守。
- 相位求解是随机重启 + 坐标下降，不保证全局最优；余量偏低的个体（如 seed 5 的 +0.65）
  也许存在更稳的相位解。
- 供体物种现在决定骨架比例、站姿、足型、体表与整颗头，但**还不影响攻击方式**——那是
  攻击层的事。一颗算出 1857 N 咬合力的牛头和一颗算出 4 N 的蛙头，目前在战斗里没有区别。
- 头上的毛只是**把头骨整个外扩一圈**，没有毛流、没有鬃、没有蓬松的边缘——肢体层的
  `part_coat` 那些单根毛簇，头颅层还没有对应的一层。所以远看是对的，凑近看是一块光滑
  的皮。
- **两只兽（seed 2、4）现在卡在"膝关节埋进核心"上。** 这是加了避让之后的代价：那两条
  腿的落点与邻居挤得太死，姿态求解器在"穿邻居"与"穿自己身体"之间只能挑一个，掰落点
  又被静态稳定余量挡住（掰开就站不住）。互穿是 0，埋是 f=1.01 与 1.41（刚过等值面）。
  真正的出路在**落点那一层**：`locomotion.place_feet` 摆点时应该知道腿有多粗，而那需要
  先解一遍载荷——层间的环得在那里拆，不是在这里调权重。
- 碰撞检测用的是**胶囊近似**（轴 + 两个半尺寸的几何平均），不是真正的 OBB 相交。方块
  的角上会被低估、扁平件（耳廓、唇缝）会被高估。阈值 0.75 px 是按这个近似定的。
- 掰落点会改变支撑多边形，虽然每次都重新量了静态稳定余量、掉得太多就退回，但**步态的
  相位是在旧落点上优化的**——掰开之后只重跑了一次 `optimize_phases`，没有回头重解整个
  步态。余量仍然合格，但不再是那个基因组的最优解。
- 头的力学在**供体的真实尺度**上算，输出的比例再等比放大到模板长度。真放大两倍的头需要
  相对更粗的骨（截面按平方涨、质量按立方涨），这一点没有建模——好处是它读得出是谁的头，
  代价是它在自己的尺度上偏轻。
- 颈**不存在**：头直接缝在核心表皮上，朝向就是挂载点法向。所以背上那颗头就是朝天长的、
  胸口那颗朝地——正典要的就是这个不合理，但也意味着头没法转、没法低头吃东西。
- 牛角只卷 11°（近乎一根横着的直角）。储能判据把短角算得很粗，而 κ=(1−k)/d 里 d 一大
  曲率就小。真牛角多在 40–90°，这一条偏直。
- 肌腹"粗不过所在那一节长度的一半"是解剖比例，不是推导；装不下的那份记为"埋在体内"。
- 关节活动范围（ROM）没建模：被迫改折向的肢只在报告里标出来，不拦。
- 大腿在重载肢上仍是一团粗肉——那是 1381 kg 压在捡来的腿上算出来的真实需求，不是渲染
  问题（现在至少会向膝收细，不再是一块等粗的方砖）。可辨识度靠膝以下（管骨/肉垫/蹄/
  禽爪）与体表承担。
- 关节处只按"骨+腱+皮"收细，**没有关节头**。真实的膝踝有膨大的骨骺（股骨髁的宽度是
  骨干的两倍多），看上去是"骨节"。按软骨接触应力反推过：即使把跨关节的肌力算进压力，
  这个尺度上也只有 0.5–0.8 px，正好落在现在的包络里——所以没有加，加了就是编的。
- 皮只是材质和裂口，**没有厚度**（2–5 mm 不到十分之一像素）。皱、疣、毛孔这些更细的
  表面结构在这个分辨率上无从表达。
- 核心动画只有直线蠕动，没有转向/起停；爬↔走的**过渡动画**也还没有（切换判据已推出，
  但两套姿态之间没有 blend）。
- 芽只是未分化组织，长满之后换成什么几何要等部件层。
- 爆体动画只覆盖崩开后约 1.5 秒；碎片真正各奔东西是运行时**各自成为独立实体**之后的事
  （用它们自己解出来的 crawl / 步态）。所以动画里碎片落地时仍挨得较近，末帧散度只有
  静止的 1.55 倍。
- 碎片的存活线 `VIABLE_MASS` 是个拍定的质量阈值，没有从"表面积/体积比在末法环境下失水"
  之类的一阶模型推出来。
- 分裂只解了"分成两半"，没有连锁分裂（分完的半边继续分）。
- 碎片横过去只有 6 格体素（VOX=2），单格在这个尺度上仍然显得大。真要更细，得让体素尺度
  随个体大小变——那是把 `VOX` 从模块常数改成参数的一层重构，没做。表面抖动已经按体长
  缩放（`slab_box(rough=)`），那只解决了"砸成碎石"，没解决网格本身的粗。
- 碎片蠕动的伸缩沿**模型主轴**做（骨骼缩放只能沿轴）。默认碎片 forward 与 −z 对齐 0.999
  所以看不出来；若哪块碎片的爬行方向是斜的，伸缩轴会与前进方向差开，自检卡在 0.7。
- 乱抽里有**四处构造量**（不是推导量），集中说明：抽搐相位、每一拍发不发、常驻漂移的
  周期数与相位、频率上限的逐槽错开。四处都是为了打散同步，理由写在 core_anim 各自的
  注释里。根因是同一个：17 个挂载点的几何几乎一样，从几何推出来的节律必然也几乎一样。
- `FLICK_MAX_HZ` 是**渲染/知觉的界，不是物理的界**。梢节力臂只有零点几像素，按速度上限
  反推是 69 Hz（已经不是抽是振，采样数也会爆）。真正的物理上界该来自组织最大应变率，
  但仓库里的 `STRAIN_RATE` 是整体蠕动的慢速率，拿来当肌肉快抽的界会算出 0.42 Hz 把动画
  压死。缺一个像样的模型，所以明写成常数。
- 芽的摆角上限 `BUD_FOLD_DEG` 是常数。试过按"周围哪边最空"逐槽推，17 个槽在满长/七成/
  短茬三档下**全部**顶到上限——核心整体是凸的，绕根部转不到 90° 的方向都在切平面外侧。
  那个版本已删：算出 17 个一样的数，看着像推导其实是常数。
