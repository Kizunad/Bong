# 异变缝合兽 建模流水线

正典：`docs/worldview.md` §七 L735 · 图书馆《异兽三形考》§兽·噬 / 《异变图谱·残卷》其三。

> 非凭空生，乃数兽相吞融成。……不是物理接合——是一层层组织的重新编织，骨对着骨重新接，
> 皮对着皮重新缝。这不是魔功。这是一种余不知名的**塑性再生**。

三形（噬元鼠 ✅ / 拟态灰烬蛛 ✅ / 缝合兽）之末。此前客户端只有 4 骨 5 方块的占位。

## 设计主轴

缝合兽和其它生物的根本区别：**它没有固定形态**。每一只都是不同几只野兽的残骸长到一起的
结果。所以这条流水线产出的不是"一个模型"，而是**一个生成器**——核心固定，肢体/头颅由
基因组随机装配。

三层：

| 层 | 内容 | 状态 |
|----|------|------|
| 核心层 | 黏状核心本体 + 挂载点 + 癒合痕 | ✅ |
| 基因组 | 挑槽 / 挑部件种类 / 供体物种 / 尺寸——一只兽的配方 | ✅ |
| 运动层 | 骑乘高度 + 步态（由肢体几何推导）| ✅ |
| 核心动画 | 无肢阶段九条动作：蠕动 / 搏动 / 扑咬 / 包裹 / 嫁接 / 爆体 / 分裂 / 受击 / 死 | ✅ |
| 碎裂层 | 分裂 / 爆体碎片 / 各碎片逃窜 / 繁殖闭合 | ✅ |
| 部件层 | 头颅与肢体的真实几何（鼠/狼/猪/牛/羊/鸡/兔/狐/蛙 + 蛛足/兽腿/禽腿/触手/退化肢） | ⬜ |
| 攻击层 | 逐肢攻击方式（由该肢的种类与长度派生） | ⬜ |

## 核心层：一切都从同一个隐式场里派生

核心不建成箱子——箱子是"设计过的形状"，而这东西没有被设计过。改用各向异性高斯和：

```
f(p) = Σ wᵢ · exp(-|(p - cᵢ)/sᵢ|²)      等值面 f = 1 即表皮
```

四件东西全部从这一个场里掉出来，没有一件是手摆的：

| 派生物 | 怎么来的 |
|--------|---------|
| 几何 | 等值面体素化 → 逐层贪心矩形合并 → **只留表层**（内部块永远看不见） |
| 骨骼 | 每体素归属于对它贡献最大的**正权** lobe，lobe 即骨 |
| 癒合痕 | 两个 lobe 在表面的交界处即是痕——与骨骼分段共用同一划分 |
| 挂载点 | 从核心内部射线求表面点，法向取 `-∇f`，girth 由局部平坦度定 |

**负权 lobe（`GROOVES`）用来刻沟**：高斯和永远是凸的，只加正权必然鼓成一只圆面包。
交界处刻沟，才读得出"几团东西挤在一张皮里"。负权段不参与 `owner()`，不抢骨骼归属。

## 两条不许改回去的决策

**① 不对称是硬约束，不是缺陷。** `lump_l` 长在左肋、`lump_dorsal` 偏右背、`nodule_r`
在右后。自检**断言不对称度 ≥20%**（当前 32.4%），报错文案直接写明"别去平衡 LOBES"。
`voxel_rig.mirror_problems` 在这里是反着用的——镜像件缺失是期望行为。

**② 融合痕不是缝合口。** 没有线、没有针、没有等距横扣——那是人造缝合的读法。正典写的是
自体"塑性再生"，留下的是不规则隆起：粗细逐段随机、一成几率断开（融合彻底处无痕）、
一成几率堆成肉瘤。自检卡「粗细跨度 ≥0.35」+「至少一处肉瘤」防它被做回等粗等距。

## 运动层：步态是算出来的，不是调出来的

**肢体是复摆。** 绕髋自然摆频 `f = (1/2π)√(MgD/I)`，均匀杆退化为 `f ∝ 1/√L`：长肢慢、
短肢快。这是物理，不是风格。

**一只兽只有一个速度 ⇒ 错拍是推论。** 一个身体周期内第 i 条肢必须走整数步
`n_i = max(round(f_i/f_body), ⌈v/(f_body·s_i^max)⌉)`——第二项是"跟不上就碎步"。
于是短腿一周期迈两三步、长腿迈一步。**缝合兽走不出齐步是算出来的**，不是为了怪而
故意错开。实测 10/10 个体走非 1:1 步态，最多出到 **1:2:3:4**。

**骑乘高度是自变量。** 撑高则短肢够不着地被踢出承重集，蹲低则长肢折起、可达半径缩水。
高度写死的话，凡是短到能迈两步的肢都踩不到地，错拍会自我抵消——实测一条 12.9 长的鼠腿
在 y=14 的髋位下 `reach=0`，直接掉出步态表。所以扫一遍 Δy 取"承重肢最多且伸展度最舒适"
的解，顺带得到这只兽是蹲伏还是撑起。

**相位由静态稳定解出来。** 肢体位置是随机挑的，可能一侧三条另一侧一条。约束是任一时刻
≥3 只脚着地、且**核心体积质心**（不对称的，x=−0.28 z=+1.47）的地面投影落在支撑多边形
内且有正余量。解不出来的基因组站不住，重采样——合法性归 `genome.validate`，站不站得住
归力学。

自检把这些全变成断言（`check_gait.py`）：摆频与解析解对拍 / **支撑相世界系不滑步**
（体坐标位移必须是 `stride×duty` 而非 `stride`，差一个 duty 因子就是每步都在蹭地，
初版就写错了）/ 不过伸 / 触地 / 支撑数 / 稳定余量 / 循环周期性 / 可复现 / 错拍率 ≥60%。

## 核心阶段动画：还没有腿的时候

缝合兽不是刷出来的成品——它先是一团核心，靠捡尸体一件件把部件长进去（正典那头幼兽只有
三条腿，第四条从野狗尸体上"借"来，花了约七日）。**无肢阶段是它必经的一段人生**，需要
一整套自己的动作，不能拿有腿的步态凑。

**蠕动和步态是同一条物理约束**：着地的那一段在世界系里必须静止，只是"脚"换成了身体的
"锚段"。双锚循环——相 A 后段锚地、前段前伸 d；相 B 前段锚地、后段跟上。净前进 d 是
**推出来的**。自检把每周期净位移加回去，验锚段世界位移为零（实测 0.0000 px）。

体积严格守恒：拉长时 `scale_xy ∝ √(L₀/L)`，实测波动 4.44e-16（机器精度）。

**爬得比走慢是算出来的**：`v_crawl = d × f`，而 `f = rate/(2d)`，所以 `v = rate/2`
——**只取决于组织收缩速率，与拉伸幅度无关**。算出 0.19 格/s，而有腿步态 0.56–1.10 格/s。
没捡到腿之前它又慢又脆，这就是它必须去捡尸体的原因；进化压力是算出来的，不是设定的。

**芽的几何按满尺寸建，当前生长度由 bone scale 表达**（休眠 0.10）。反过来做行不通：
Blockbench/GeckoLib 几何是静态的，缩放一个 0.44 半径的小疙瘩永远长不出东西，实测整条
嫁接动画看不见。运行时服务端直接驱动 `bud_<槽>` 的 scale，动画只是参考曲线。

**父骨的 R/S 会作用在子骨的位移上**（写形变动画必看，这坑踩了两次）。子骨写的 `pos`
会被父骨的旋转和缩放一起变换，所以「子骨位移 = 目标 − 父骨位移」这种加法补偿只在父骨
纯平移时成立。两次实测：蠕动中段拉伸 k=1.4 时 core_fore 凭空多跑 4.19px（锚段变蹭地）；
爆体里父骨同时鼓胀 scale 1.2 且翻滚，nodule_r 被父链放大到 −32px，落地钳制怎么调都拦
不住。**正解不做近似**，用父骨完整世界矩阵反解（`core_anim.place_world`）：

```
W_parent · (o + pos) = o_world_rest + offset   ⇒   pos = W_parent⁻¹·目标 − o
```

调用要按父先于子的顺序。还有一条附带的：父骨是谁得按**真实父骨**取——`nodule_r` 的父骨
是 `core_hind` 不是 `core_mid`，一律减 `core_mid` 会把它连同挂在它上面的芽甩到地下。

（不做这层桥接也不行：中段 z 缩放留在 1.0 时，前后段一分开，原本刻出来的凹槽会被拉宽
成可见裂缝——3/4 视角实测。）

七条动作各自的设计约束写在 `core_anim.py` 的 docstring 里，自检在 `check_core_anim.py`：
不滑步 / 净前进 / 体积守恒 / 循环接缝 / **各 lobe 异步搏动**（同步会读成"一只动物在喘"，
断言互相关 <0.85，实测 0.249）/ 嫁接单调且有停滞（匀速长大读成技能特效）/ 死亡逐 lobe
依次泄气且赘生物先瘪 / **扑击蓄放速度比 ≥2.5**（实测 ×10.8，恐惧的唯一来源）/
包裹张合幅度 ≥0.5 且咽下后主体变大（吃进去的得有去处，凭空消失是吞质量）/
受击回到静止 / 不穿地。

**何时从爬改成走，是推出来的**：`locomotion` 判定「够得着地的承重肢 ≥3」即可用步态，
否则只能蠕动。这条判据和基因组合法性、稳定性求解共用同一套几何，不是另外定的规则。

## 碎裂 / 分裂 / 繁殖：这东西怎么变成更多这东西

粘住这几团肉的只有那几道癒合痕。所以撑不住就沿最弱处裂开（分裂）、被打死就所有弱痕
同时崩（爆体）、碎片活下来捡尸体重新长成一只（繁殖）。

**从哪儿裂开不需要画**：癒合痕就是两个 lobe 的表面交界，交界体素数就是那道接合的
**面积**，也就是强度（`core.weld_areas`）。应力升高 = 逐条切断弱于阈值的接合，剩下的
连通分量就是碎片。同一只兽每次裂法一致、可复现。实测应力递增给出 1→2→3→4→6→7 块。

**碎片就是一只小兽**：它带走覆盖的挂载点，也就带走那些肢体，于是逃窜步态**直接走
`locomotion.solve()`**——够得着地的承重肢 ≥3 就跑步态，不够就蠕动爬。「不同部位往不同
方向逃窜」不是特效，是每块碎片各自解出来的。

**逃窜速度必须互不相同**，否则只剩方向不同。尺寸无关的量是**应变率**不是绝对收缩速度，
所以 `v_crawl = 应变率 × 体长 / 2` **正比于体长**：大块爬得快、小碎片爬得慢。实测四块
碎片 0.060 / 0.082 / 0.114 / 0.122 格/s。

**健康分裂是最小割**：撕开要切断跨越裂面的**所有**接合，不是一条。初版只枚举单条边，
7 个 lobe 的接合图连得密，删一条几乎断不开，永远报"无可行切面"——那不是它分不了，是
模型问错了问题。改暴力枚举全部二分（64 种），要求两侧各自连通且质量达标，取割最小的。

**质量必须摊得开**：`core_mid` 曾占全身 45%，爆体时只有主体活得下来，「各部位分头逃窜」
根本不成立。摊平后最大一团 28.3%、四团过存活线。自检卡 ≤34%。

`check_fission.py` 八项：质量摊平 / 应力单调（应力升高不该让它重新粘上）/ 质量守恒 /
**动量守恒**（Σmᵢvᵢ=0，不守恒就读成"被炸飞"而非"自己崩开"）/ 逃窜异速 / 最小割分裂 /
繁殖闭合（碎片基因组是亲代真子集，肢体不漏不重）/ 爆体确实散开。

## 碎片模型：撕下来的那块自己是什么

**不是把核心等比缩小。** 三件事必须重算，全部从既有的场里推：

**创面**——少了另一半，母体身上原本埋在内部的体素就成了表面（`core.surface_of` 按 lobe
子集重跑表层判据）。哪几格是创面也是推的：缺失的邻居在母体里是实心的，肉原来就在那儿。
断口的法向取**缺失邻居方向**而不是场梯度（场在体内光滑，−∇f 在断口指向随机），材质另起
一张表（断口露的是内部组织，不该有黏液也不该有膜），抖动幅度 ×1.9（皮是长平的，断口
是扯出来的）。

**重新分节**——只带一团肉的碎片是一块刚体，而蠕动要两个锚轮流抓地，一根骨做不到。所以
沿爬行方向按**质量**三等分（按长度分会在两端切出两三格的薄片）。爬行方向同样是推的：
带头槽的朝头槽法向（将来的前端），没带头槽的朝**背离母体**的方向（断口在身后）。

**组织预算**——芽的料不是凭空来的。`core.graft_budget` 从正典"一次一条、每条七日"反推出
同时能持有的未分化组织量；碎片按质量比缩，于是它**长不出母体那样的触手**。这就是它非去
捡尸不可的理由，是体积算出来的，不是设定的。

一样母体有而它没有的：**癒合痕**。只带一团肉的碎片一道痕都没有——痕是两块组织长到一起
的记号，它只有一块。缝合兽不是生下来就缝合的，那身痕是它一辈子吞下去的账。

**分裂要付代价**：骑在裂面上的挂载点会被撕坏（那片皮一半跟着另一半走了），两边谁也带不
走。所以分出去的两半加起来比母体少几个槽，少的正好在裂面上（实测健康分裂丢 1 个、
爆体丢 3 个）。`check_fission` 的繁殖闭合相应改成"掉肢只允许掉在被毁的槽上"。

碎片动画（`fragment_anim.py`）用的是和母体**同一套约束**，只是身体换了：行程 = 自己的
锚段间距 × STRETCH，频率与体长无关，于是速度正比于锚段间距——`core_fore` 那块锚段只隔
5.0px、母体隔 21px，它只能爬 0.045 格/s（母体 0.188）。**它跑不掉**，所以它得躲、得等。

## 触手：生长与乱抽

**每个挂载点一条生长动画**（`graft_<槽>`，17 条），时长各不相同：组织合成速率是整只兽的
代谢常数，所以长一条芽要多久**正比于这条芽的用料**（`core.bud_tissue` 算并集减去埋在体内
的部分——按包围盒相加会高估一倍以上）。实测 0.50–3.21s、17 个各不相同的值。下限 0.50s
是可读性的物理下限（五段推进/停滞 × 每段至少两 tick），`vest_dr` 按用料算出来只有 0.11s。

**乱抽**（`core_thrash`）：每个挂载点同时冒出一小截，各自急抽。三条主张，逐条量：

- **抽多快有上界**：没有哪个部位能比它扑击时更快，于是 `f ≤ V_max·ATTACK/(摆角×力臂)`。
  力臂就是那条芽伸出去多长，所以短茬甩得快——和肢体的复摆律（`f ∝ 1/√L`）同源，只是这里
  被速度封顶而不是被重力回复，指数是 `1/L`。
- **茬只能是短的**：同一份组织预算摊到 17 个槽上，骨缩放只有 0.42。全身长满触手它负担不
  起。而短茬力臂小、抽得更急——"又短又急"是同一个预算推出来的两件事。摊出去的料从自己
  身上抽，本体等体积缩小（自检断言芽增 = 本体减，实测 452 px³ 对 452 px³）。
- **集体找不出节律**：这条**不是**靠频率散开的。17 个槽 girth 大多挤在 3.2–4.0，力臂跟着
  挤，算出来的次数集中在 5 上下（拉长循环也没用，实测四档下不同值只有 4/4/5/6 个）。
  相位均匀铺开也救不了——同频信号相邻相位只差周期的十五分之一，5Hz 下就是 12 毫秒，眼睛
  看到的是一圈茬依次抽过去的**行波**。真正管用的是**每一拍发不发各自决定**：痉挛本来就不
  是节拍器。加上这一条之后两两轨迹互相关从 0.90 掉到 0.47。

载体在乱抽时**一动不动**——一堆东西在抽而载体是静的才瘆人，跟着一起晃就读成"整只在抖"。

芽的形状为此改过：原来三节、末节收到根部的 0.50，乱抽渲出来每条都像贴在皮上的鳞片；
改四节、收到 0.28、长细比 2.7:1 → 3.4:1 之后才读得出"一根"。

## 已知局限

- 顶视轮廓仍偏矩形——体素网格轴对齐的固有代价，靠抖动和跨度上限只能缓解不能消除。
- 「几只野兽融成一只」这个读法目前只靠癒合痕承担；真正落地要等部件层把头和肢挂上去。
- 挂载点的 `girth` 目前区分度窄（3.7–4.1），赘生物上的槽还没被真正卡住——等部件层
  有粗细不同的真实部件时才知道这个量够不够用。
- 步态只解了**直线行走**：转向、起步/刹停、被击退、爬坡都还没有。
- 稳定性判据是**静态**的（质心投影必须始终在支撑多边形内）。真实动物奔跑时是动态平衡，
  允许短暂失稳；沿用静态判据会让奔跑步态偏保守。
- 相位求解是随机重启 + 坐标下降，不保证全局最优；余量偏低的个体（如 seed 5 的 +0.65）
  也许存在更稳的相位解。
- 供体物种目前只影响**尺寸**，还没影响几何形状与攻击方式——那是部件层/攻击层的事。
- 核心动画只有直线蠕动，没有转向/起停；爬↔走的**过渡动画**也还没有（切换判据已推出，
  但两套姿态之间没有 blend）。
- 芽只是未分化组织，长满之后换成什么几何要等部件层。
- 爆体动画只覆盖崩开后约 1.5 秒；碎片真正各奔东西是运行时**各自成为独立实体**之后的事
  （用它们自己解出来的 crawl / 步态）。所以动画里碎片落地时仍挨得较近，末帧散度只有
  静止的 1.55 倍。
- 碎片的存活线 `VIABLE_MASS` 是个拍定的质量阈值，没有从"表面积/体积比在末法环境下失水"
  之类的一阶模型推出来。
- 分裂只解了"分成两半"，没有连锁分裂（分完的半边继续分）。
- 碎片横过去只有 6 格体素（VOX=2），单格在这个尺度上仍然显得大。真要更细，得让体素尺度
  随个体大小变——那是把 `VOX` 从模块常数改成参数的一层重构，没做。表面抖动已经按体长
  缩放（`slab_box(rough=)`），那只解决了"砸成碎石"，没解决网格本身的粗。
- 碎片蠕动的伸缩沿**模型主轴**做（骨骼缩放只能沿轴）。默认碎片 forward 与 −z 对齐 0.999
  所以看不出来；若哪块碎片的爬行方向是斜的，伸缩轴会与前进方向差开，自检卡在 0.7。
- 乱抽的**相位**是全篇唯一一处构造量而非推导量（同频的那几条在周期内均匀铺开）。发不发
  那一层是确定性噪声，也不是从组织力学推的。
- 芽的摆角上限 `BUD_FOLD_DEG` 是常数。试过按"周围哪边最空"逐槽推，17 个槽在满长/七成/
  短茬三档下**全部**顶到上限——核心整体是凸的，绕根部转不到 90° 的方向都在切平面外侧。
  那个版本已删：算出 17 个一样的数，看着像推导其实是常数。
