# poison_dragon 补动画（Round 1）

骨架与 `bone_dragon` 完全相同（geo 骨名与枢轴逐一一致）：`pelvis`（后腿、尾、腰的根）> `waist` > `waist2` > `chest`（前臂、双翼、颈）> 颈 3 节 > `head` > `chin`。朝向 -Z。
注意 `chin` 静止旋转是 X+60（嘴默认大张），闭嘴要写 `chin` 绕 X ≈ -48，本组新段都显式写了。
已有段 `idle` `attack` `walk` 未改。

## 自查
- 入地：hurt 0.00 / death 0.00 px；终态最低点距地 ≤ 2px（不悬空）。
- **预览工具的黑块**：翼膜在预览里一部分渲成黑色，是透明像素被预览按黑底渲染，不是动画问题。
- **geo 与 PNG 尺寸不一致（既有问题）**：geo 声明 2048×2048，PNG 实为 256×256。GeckoLib 按 UV 比例取样所以游戏里正常；预览为此用临时放大副本（`preview_large.py` 说明），不改资源。
- 翼的方向与直觉相反：左翼翼根绕 Z 取负才是抬翼，已在 `wing_values` 注明。
- 与 `bone_dragon` 共用同一套构造函数，两只的 hurt/death 骨骼动作相同、仅骨龙的 hurt 多一串衰减抖动；视觉差异靠贴图。若要求「每只一眼可辨」，需要调度确认是否接受。
