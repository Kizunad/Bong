# living_pillar 补动画（Round 1）

骨架：`bone2`（底座）> 12 节竖直链（bone4 … bone12，无静止旋转）；`bone14/15/16` 是底座须根，`bone13` 是柱身探出的口器。绕 X = 前后弯（正 = 向 -Z 前倾），绕 Z = 左右弯。
已有段 `idle` `attack` `big1.5` 未改。

| 段 | 时长 | 循环 | 说明 | GIF |
|---|---|---|---|---|
| `walk` | 1.6s | 是 | 原地蠕动：底座一缩一伸，弯折沿柱身向上滚（逐节相位后移，越高摆幅越大），须根交替扒地，口器开合。位置不动 | `living_pillar/walk.gif` |
| `hurt` | 0.6s | 否 | 冲击波自根部逐节上传（每节先被顶弯再反弹，柱顶甩得最狠），底座上挫，口器抽搐张开 | `living_pillar/hurt.gif` |
| `death` | 2.6s | 否 | 原地剧烈抖动 → 根部一软整根向前倒下（底座 X 0→92°，顶端滞后）→ 砸地回弹 → 瘫软，终态保持（柱身贴地略上弓） | `living_pillar/death.gif` |

## 自查
- 入地：walk 0.00 / hurt 0.00 / death 0.57 px（倒下途中底座侧缘）。
- 循环段首尾同值已程序核验。
- 12 节累计弯曲很敏感：第一版 death 因每节叠加前弯，柱顶卷进地里 105px，已把摔地后每节弯角压到 ~1°，并让终态略上弓。以后再调请先看 `preview_large.py --ground`。
- 柱子 294px 高，GIF 里细节小；`big1.5`（整体 1.5 倍缩放）是旧段，我的新段不带缩放，是否需要由接线阶段决定。
