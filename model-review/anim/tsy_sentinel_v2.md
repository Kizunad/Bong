## 动画清单

| 动画 | 时长 | 循环 | 说明 |
|---|---|---|---|
| idle | 4.4s | 是 | 石甲巨像的重量感而非生物呼吸感：极缓慢的左右重心切换、头部慢扫视，手臂基本静止只有极轻微的拳头张合；腰带前后襟与两侧腰石片轻幅摇摆 |
| walk | 1.8s | 是 | 沉重的交替步态：膝关节随摆动相屈折，髋部每次落脚顿一下（一步两次冲击），躯干反向拧转配合跨步，手臂小幅反向摆动；布甲随步伐大幅摆动 |
| attack | 1.1s | 否 | 右臂高举后撤蓄力 → 躯干拧转发力 → 石拳砸出 → 收回，左臂反向配平、腿部承重前顶；布甲被带得甩起来 |
| hurt | 0.45s | 否 | 短促的沉重后仰，头部甩动，双臂略微一缩，布甲被震得一晃 |
| death | 2.1s | 否 | 先一个前栽的踉跄（重心前冲），膝盖撑不住后彻底向前扑倒，髋部沉到贴地（由 check_ground 贴地）——石像倒塌没有缓冲，一次性砸下去 |

## 参考前例

- 骨架：`gen_rig.py` 的 `TSY_SENTINEL_BONES` / `_sentinel_side_bones`（本轮未改）。
- 任务卡：「重甲巨像守卫」——要的是苏醒时的重量感，不是生物的呼吸感；手臂/腿部关节齐全，可以走正常的屈膝步态。
- 本轮新写 `tsy_cloth` 辅助函数统一驱动前 / 后襟与两侧腰石片、碎布，错相摆动手法是本仓已有写法（见 daoxiang/skull_fiend 的多骨错相布料），具体数值从零重写。

## 自查发现的问题

- attack 里 `arm_r` 的 z 轴外摆幅度（18°）偏大，从顶视图看手臂甩得比预期更远，视觉上有点像「侧挥」而不是「下砸」；Round 3 可以把 z 分量收窄、x 分量（前砸）加大，让「重拳砸地」的意图更清楚。
- death 倒塌时膝盖折角（70°）和整体前倾（60°）同时叠加，侧视看起来偏向「跪着扑倒」，不是纯粹的失去支撑直接倒地；Round 3 可以调整膝盖与髋部时序，让倒地动作更干脆利落。
- 腰带前后襟与两侧腰石片、护膝共六片布甲目前只用了两组相位错开，近距离细看可能还是显得同步感偏重，没有像骨煞小颅那样做出明显的主次节奏差异。
