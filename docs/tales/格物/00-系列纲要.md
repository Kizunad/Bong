# 格物修仙 · 网文爽文 · 设定纲要

> 末法残土 · 网文向 · 第一人称 · 纯爽文(HE/开放)
>
> 卖点一句话:**满世界的修士跪着求灵气,只有他站着量灵气。** 别人靠机缘,他靠算账;别人拿命拼,他造傀儡替他拼。

---

## 金手指:格物体系

不是系统,不是召唤,不是老爷爷。主角的外挂是**一颗理工脑 + 一双能把灵气看成"场"的眼睛**,合起来一句话:**他能把这世界读成攻略。**

- **灵气可视化**:醒灵自带的灵气感知,在别人眼里是模糊的"浓淡",在他眼里是**带梯度、带方向、带数值的压强场**。
- **天道说人话**:这世界的天道把规矩全写在脸上——压强、梯度、守恒、半衰、流量。别人当玄学跪着求,他当物理读着用。**他识字,满世界就他识字。**
- **真元封物**:把真元挤进物体、刻阵纹锁住——这是炼器/阵法/傀儡的入门门槛,大宗门压箱底。他凭格物脑无师自通,起步就甩开所有人一个身位。
- **越用越强**:每一次实验都让他更懂规则,更懂规则就能压更狠的榨更多的算更绝的。金手指不是定值,是复利。

**爽的根**:读者跟着他,第一次发现"原来修仙世界的玄学全是可以算的物理",那种"我比这世界所有NPC都清醒"的智商碾压快感。

## 主角 & 声音

- **身份**:穿越者,醒来即醒灵,带前世图纸公式的脑子,没师门没功法没人脉。对人只说"前世",任人误会成修仙转世,他不解释。
- **路线**:**傀儡师**。逻辑极硬——既然真元出窍就废、修仙就是拿命拼,那就别拿自己的命拼,**造机器替我拼**。傀儡=异变兽骨(结构)+阵纹(控制)+他的真元(动力)。一人发展成一支傀儡军团 + 幕后贸易/情报网。
- **声音**:冷、贱、爱算账,自带吐槽。短句快切,内心OS密,对玄学修士有种"你们都好憨"的优越感。用世界本身的词说世界的物理(灵压零点三、真元几点、几格几里),不蹦现代名词,但读者一眼看出这是个工程师在降维打击。
- **人设标签(爽文用)**:扮猪吃老虎(藏实力)、苟得住(算账高手从不送)、搞钱狂(骨币/情报/傀儡贸易)、幕后大佬(后期隐于六域之后,谁都猜不到那个传说级游商傀儡的主人是他)。

## 升级线:境界 × 傀儡军团(双轴升级)

修仙小说的爽在"数值上涨看得见"。本作双轴一起涨:

| 阶段 | 自身境界 | 傀儡 | 局面 |
|------|---------|------|------|
| 起手 | 醒灵 10点 | 第一具粗胚骨架(替他挡鼠/守坐) | 荒地求生,智商碾压新手村 |
| 早期 | 引气 | 量产工蜂傀儡(采药/搬运/望风) | 别人用脚找灵气,他用傀儡铺一张测绘网 |
| 中期 | 凝脉→固元 | 战斗/跑商傀儡;**第七具「瘸七」诞生,后丢失** | 搞钱,扮猪吃老虎打脸地头蛇、宗门子弟,贸易网铺开 |
| 后期 | 通灵 | 傀儡军团 + 坍缩渊采矿队 | 一个人=一支势力,碾压宗门残党 |
| 结局 | 化虚 / **隐藏大能** | 真身永不露面,全凭傀儡分身行走六域 | 连天道都锁不定他——因为他从不暴露真身 |

**真元封物会漏(半衰)是约束不是绝症**——他靠更好的兽骨、更紧的阵纹、更勤的回充把"漏"压到最低,这正是他比所有人强的地方:**别人认命,他优化。** 写作时把"漏"当工程难题、当下一个爽点的来源,不当悲剧。

## 爽点机制清单(每隔几章必须命中一个)

1. **智商碾压**:把别人眼里的玄学/绝境,当物理题三两下解掉。
2. **扮猪吃老虎**:藏实力,被人小看→关键时刻亮一手→对方傻眼。
3. **打脸**:地头蛇/宗门子弟/反派看不起他的"奇技淫巧",被现实教做人。
4. **搞钱搞资源**:用信息差和精算,把交易做成稳赚,骨币/丹药/兽骨滚雪球。
5. **幕后大佬**:傀儡替他出面,真身永远不露,传说越传越神,谁都不知道幕后是谁。
6. **碾压式越级**:用傀儡海/算计/地形,以弱境界吃掉高境界,反套路修真常识。

## 瘸七:中期丢失的作品之一(江湖传说的真相)

`docs/library/world/骨币半衰录.json` 写死的事实**全部保留,只改"它在主角心里的分量"**:

- 瘸七:游商傀儡,左腿短半寸"步子一晃一晃";主人在万里之外、不知姓甚;有人抢它→次日被跨地图追杀至死;六域之间走了十五年无人敢动;问价答得快、问来历答得呆。
- **真相**:瘸七是主角**中期**(凝脉→固元那段)造的**第七具**游商傀儡,曾是他贸易网的一颗节点。后来**丢了**——(择一:卷进一次区域域崩失联 / 被劫后自锁逃脱再没归队 / 主角弃了那片地盘没去回收)。它带着旧例程,继续在六域之间一晃一晃地走、交易,十五年没停。
- **"主人不知姓甚"** = 主角**早把它忘在脑后**了。那时他已是隐藏大能,一具中期丢失的旧傀儡,不值得他分神去捡。
- **"动它就被跨地图追杀"** = 不是主角亲自盯,是他庞大傀儡/情报网的**常驻协议**:凡带他阵纹签名的造物被人动手,网络自动处理。**连他丢掉的破烂都没人敢碰**——这恰恰是他可怕之处的侧写。
- **揭底爽点**(后期):读者跟着主角一路走来,早知道瘸七是谁的手笔。当六域把瘸七传成"神秘莫测的传说级游商傀儡、背后是不可知的大能"时——真相是它只是主角**中期随手丢的一件半成品**。这个落差 = 主角到底走了多远的标尺。
- 短腿是**工程妥协**的梗(左右腿封真元速率不对称,短半寸反而走得稳),主角懒得修,"它走得稳就行,好不好看是审美问题不是工程问题"——人设趣味点,贯穿全程。

## 冲突源(爽文要有挨打的对象)

- **地头蛇散修 / 拾荒者**:早期试图坑他、抢他,被反杀打脸。
- **宗门残党子弟**(青云残峰外门、灵泉湿地丹宗余孽):瞧不起野修和"奇技淫巧",正统vs格物的路线之争。
- **天道**:不是反派,是终极难题副本。别人怕天劫,他研究天道行为模式、造欺天阵戏耍它——把天道当可破解的BOSS机制,而不是不可抗的命。
- **同行傀儡师/炼器师**:证明他的路子比"祖传秘法"强。

## 章节节奏规范(网文向)

- **第一人称**,快节奏,短段落,一句成段常态。
- **每章2000-2800字**,章末必留钩(危机/悬念/装逼前摇)。
- **黄金前三章**把金手指、爽感、升级方向全立住。
- 砍掉文学向元素:不写手记协议头、不写日期落款、不写"按下不表"那类留白收尾——换成硬钩子。
- 爽点优先于细腻;但设定术语仍与 `docs/worldview.md` 咬死(灵压数值、境界、真元封物半衰、骨币温凉、瘸七细节)——**爽但不崩设定**。
- 内心OS和吐槽是主要调味,对白短而脆。

## 结局:隐藏大能(HE / 开放)

主角把末法残土当超大型工程题,一路解到**隐藏大能**——一个从不以真身示人、全凭傀儡分身行走六域的幕后存在。他甚至**解掉了天道这道副本**:别人怕天劫、怕被天道当高耗户清算,他的破法是**永远不暴露真身**——天道的索敌锁不定一个从不露面的人。六域只流传他造物的传说(瘸七只是其中最不起眼的一件),没人见过他本人,没人知道他是谁。

**收尾爽点**:当年荒地里被灰袍散修当羊牵的怂醒灵,如今是连天道都点不到名的隐藏大能;而江湖闻之色变的传说级瘸七,不过是他中期随手丢的一件旧作。落差拉满,全书收束。不虐,不强行升华——工程师把题解完了,合上图纸。
